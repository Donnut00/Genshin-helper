Genshin Helper — Cài đặt Browser Extension (v5.3.0)

Cài 1 lần duy nhất (Off-Store, không cần Store) • Hỗ trợ Chrome, Microsoft Edge & Brave

📁 Đường dẫn thư mục Extension trên máy của bạn

C:\Program Files\Genshin Helper\extension

🚀 3 Bước hoàn tất cài đặt (chỉ mất ~20 giây)

1

Mở trang Extensions

Nhấn nút copy phía trên (vd chrome://extensions hoặc edge://extensions), dán vào thanh địa chỉ trình duyệt và nhấn Enter.

2

Bật Developer mode

Gạt công tắc Developer mode (Chế độ dành cho nhà phát triển) ở góc trên bên phải (Chrome) hoặc thanh bên trái (Edge).

3

Chọn Load unpacked

Nhấn nút Load unpacked (Tải tiện ích đã giải nén), dán đường dẫn thư mục vừa copy ở trên và nhấn Select Folder. Sau đó ghim icon Paimon lên thanh công cụ!

💡 Lưu ý quan trọng khi sử dụng

  • Không xóa thư mục extension vừa nạp — Extension đọc trực tiếp từ thư mục cài đặt cố định để luôn giữ đúng ID kết nối Native Messaging với nút Bật/Tắt Server.
  • Nếu từng dùng Tampermonkey: Hãy tắt hoặc gỡ script cũ trong Tampermonkey để tránh chạy trùng lặp.
  • Người dùng 1 màn hình: Bật Chế độ 1 Màn Hình ngay trong Extension Popup và đặt Genshin Impact ở Borderless Windowed để thấy HUD Toast nổi và dùng phím Alt + Q đảo nhanh giữa Game ↔ Bản đồ.
  • Mở HoYoLAB Map: Bấm vào biểu tượng Paimon trên thanh công cụ trình duyệt → nhấn Mở HoYoLAB Map và bắt đầu thám hiểm!
